Entry for make.fun's "Sum up 18 November's world news in one image"
bounty ([news-image-20261118](https://make.fun/bounty/news-image-20261118)).

`entry.png` is a newspaper-style front page summing up Wednesday
18 November 2026 in six panels:

1. **Gulf strikes** — US jets hit a missile site on Qeshm Island;
   Iran answers with strikes on Kuwait and Bahrain.
2. **Crimea bridge falls** — a Ukrainian strike collapses the Kerch
   bridge's road arch into the strait.
3. **APEC in Shenzhen** — Xi, Putin and Trump meet in China.
4. **Alaska flips** — Peltola wins the Senate race; Democrats hold
   56 Senate seats.
5. **Measles returns** — the US loses its measles-free status after
   26 years.
6. **Voyager 1** — the first human-made object one light-day from
   Earth.

`main.ts` (Node 22, standard library only) copies `entry.png` to
`/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png` locally).
Run it with:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
